# Revitae — Shopify Custom Theme

A custom Shopify theme developed as a personal portfolio project,
converting a responsive e-commerce website into a dynamic Shopify theme.

## Tech Stack

- Shopify Liquid
- Shopify Theme Schema
- JavaScript
- HTML5
- CSS3
- Swiper.js

## Features

- Custom responsive Shopify theme
- Dynamic product and collection rendering
- Product variants
- Ajax cart
- Customizable sections and blocks
- Shopify Theme Editor integration
- Product gallery
- Responsive navigation
- FAQ
- Testimonials
- Swiper sliders

## Theme Architecture

- `layout/` — global theme layout
- `sections/` — configurable Shopify sections
- `snippets/` — reusable Liquid components
- `templates/` — Shopify page templates
- `assets/` — CSS, JavaScript and images
- `config/` — theme settings
- `locales/` — localization files

## Project

**Revitae — Shopify Custom Theme**

This is a personal project created to demonstrate hands-on Shopify theme development using Liquid, Shopify sections, blocks, schema, product objects and cart functionality.

## Demo

The project is developed on a Shopify Development Store, so the storefront may require password access.
