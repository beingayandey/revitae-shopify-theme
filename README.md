# Revitae — Shopify Custom Theme

A custom Shopify theme developed as a personal portfolio project, converting a responsive e-commerce website into a dynamic Shopify storefront.

## 🔗 Live Demo

**Shopify Store:**  
https://revitae-dtzobyio.myshopify.com/

> This project is hosted on a Shopify Development Store, so the storefront may require password access.

## 🛠️ Tech Stack

- Shopify Liquid
- Shopify Theme Schema
- JavaScript
- HTML5
- CSS3
- Swiper.js

## ✨ Features

- Custom responsive Shopify theme
- Dynamic product and collection rendering
- Product variant support
- Ajax Cart functionality
- Customizable Shopify sections and blocks
- Shopify Theme Editor integration
- Responsive product gallery
- Swiper.js sliders
- Responsive navigation
- FAQ and testimonial sections
- Promotional and marketing sections
- Mobile-first responsive design

## 📁 Theme Architecture

```text
assets/       → CSS, JavaScript and theme assets
blocks/       → Reusable theme blocks
config/       → Shopify theme settings
layout/       → Global theme layout
locales/      → Localization files
sections/     → Configurable Shopify sections
snippets/     → Reusable Liquid components
templates/    → Shopify page templates
