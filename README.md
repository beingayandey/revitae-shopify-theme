# Revitae — Shopify Custom Theme

A custom Shopify theme developed as a personal portfolio project,
converting a responsive e-commerce website into a dynamic Shopify theme.

## 🔗 Live Demo

**Shopify Store:**  
https://revitae-dtzobyio.myshopify.com/

> **Note:** This project is hosted on a Shopify Development Store.
> The storefront is password-protected because Shopify Development
> Stores require password access.

## 🛠 Tech Stack

- Shopify Liquid
- Shopify Theme Schema
- JavaScript
- HTML5
- CSS3
- Swiper.js

## ✨ Features

- Custom responsive Shopify theme
- Dynamic product & collection rendering
- Product variants
- Ajax Cart
- Customizable sections & blocks
- Shopify Theme Editor integration
- Product gallery
- Responsive navigation
- FAQ section
- Testimonials
- Swiper sliders

## 📁 Theme Architecture

- `layout/` — Global theme layout
- `sections/` — Configurable Shopify sections
- `snippets/` — Reusable Liquid components
- `templates/` — Shopify templates
- `assets/` — CSS, JavaScript & assets
- `config/` — Theme settings
- `locales/` — Localization

## 📌 Project Type

**Personal Project**

Built to demonstrate hands-on Shopify theme development using
Liquid, Shopify sections, blocks, schema, product objects,
variants and cart functionality.
